Clé d’accès partagée

Tous les agents connectés devront saisir la nouvelle clé. La clé n’est stockée que sous forme d’empreinte : notez-la de votre côté.

Secteurs

Chaque écran de mission est codé dans le jeu (copie sur clé, carte mondiale…). Ici, vous réglez les textes, l’ouverture, les indices, le fragment et les réponses acceptées.

Journal des validations

HeureSecteurAgent

Contenu

L’import remplace les textes, indices, fragments et réponses de chaque secteur présent dans le fichier, et la clé d’accès si le fichier en contient une. La progression n’est pas touchée. Gardez ce fichier hors du dossier public : il contient les réponses en clair.

Zone sensible

Réinitialiser efface toutes les validations et remet les indices à zéro. Utile après vos tests, avant le lancement.
